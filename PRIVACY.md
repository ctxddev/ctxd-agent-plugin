# Privacy policy

This repository distributes configuration for the open-source ctxd MCP bridge. It does not provide a hosted data service.

Your MCP client starts ctxd on your computer. You choose the source folders to synchronize. When the client calls a read tool, ctxd returns source content to that client. Your client and model-provider settings determine whether that content is sent to an external service. Review those settings before connecting private sources.

Installation downloads software from GitHub and Python package services. Those services handle connection and account information under their own policies.

If you contact hi@ctxd.dev for support, we use the message and contact information to respond. Do not include credentials or private source content in a public issue.

For questions about this configuration or its handling of data, contact hi@ctxd.dev.
